# 🎮 Ester Games - CCAA

Plataforma de jogos educativos para aprendizado de inglês do CCAA, desenvolvida pelo Professor Breno Vitoriano.

## 📖 Sobre

Ester Games é uma plataforma interativa de jogos educativos projetada para tornar o aprendizado de inglês mais divertido e eficaz para os alunos do CCAA.

## 🎨 Cores do Tema

- **Azul CCAA** - Cor principal
- **Branco** - Fundo e contraste
- **Vermelho CCAA** - Acentos e destaques

## 🚀 Tecnologias

- **Next.js 16** - Framework React
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Estilização
- **shadcn/ui** - Componentes UI

## 👨‍🏫 Autor

**Professor Breno Vitoriano** - CCAA

## 🏫 Sobre o CCAA

O CCAA (Centro de Cultura Anglo Americana) é uma das maiores escolas de idiomas do Brasil, fundada em 1961 no Rio de Janeiro.
